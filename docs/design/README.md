# Дизайн «Вместе»: мягкий необрутализм

Утверждённое направление визуала. Здесь живой макет главной и дизайн-токены, из которых собирается `shared/ui` (задача 3.3). Требования к экранам — в [DESIGN_BRIEF.md](../DESIGN_BRIEF.md), подписи статусов — в [DATA_MODEL.md](../DATA_MODEL.md).

## Файлы

| Файл | Что это |
| --- | --- |
| [home.html](home.html) | Макет главной: поиск, «Мои записи», фильтры по видам спорта, список и карта. Кликабельный |
| [tokens.css](tokens.css) | Все цвета, шрифты, радиусы, тени. Единственный источник, в коде значения не хардкодим |

**Как посмотреть:** открыть `docs/design/home.html` в браузере, сборка не нужна. Запасное состояние карты: дописать `?nomap` к адресу. Телефонный вид: DevTools → режим устройства, там появится переключатель «Список / Карта».

## Принципы стиля

- **Чёрная обводка 2px и жёсткая тень без размытия** (`--shadow-sm/md/lg`) у карточек, кнопок, полей, меток на карте. Это главный узнаваемый признак.
- **Пастельные заливки** только для смысла: вид спорта (палитра `--sport-*`) или статус (`--status-*`). Фон страницы голубой, карточки белые.
- **Заголовки** Comfortaa, **текст и интерфейс** Rubik. Любой текст ≥16px, основной 17px, кнопки и поля ≥48px.
- **Лёгкая «игривость»**: выбранный чип и стикеры «Мои записи» чуть повёрнуты (±1.5°). Карточки событий и формы не поворачиваем: их нужно читать.
- **Состояние не только цветом**: у бейджа всегда иконка и подпись. Режим «По заявке» на карте — метка с замком.
- Нажатие кнопки «вдавливает» её (сдвиг на тень), наведение — приподнимает.

| Подпись из DATA_MODEL | Токен | Иконка |
| --- | --- | --- |

**Виды спорта:** восемь цветов `--sport-1` … `--sport-8`. Цвет берётся по индексу (хэш `slug` по модулю 8), поэтому вид спорта, который пользователь ввёл сам, получает цвет без правок кода.

## Подключение в приложении

Tailwind v4: импортировать токены и пробросить их в тему, тогда работают классы `bg-primary`, `text-ink`, `rounded-lg`, `shadow-md`, `font-display`.

```css
/* apps/web/src/index.css */
@import 'tailwindcss';
@import '../../../docs/design/tokens.css'; /* или скопировать в shared/ui */

@theme inline {
  --color-bg: var(--color-bg);
  --color-surface: var(--color-surface);
  --color-ink: var(--color-ink);
  --color-ink-muted: var(--color-ink-muted);
  --color-primary: var(--color-primary);
  --color-accent: var(--color-accent);
  --color-danger: var(--color-danger);
  --font-display: var(--font-display);
  --font-sans: var(--font-body);
  --radius-sm: var(--radius-sm);
  --radius-md: var(--radius-md);
  --radius-lg: var(--radius-lg);
  --radius-xl: var(--radius-xl);
  --shadow-sm: var(--shadow-sm);
  --shadow-md: var(--shadow-md);
  --shadow-lg: var(--shadow-lg);
}
```

Шрифты подключаются в `index.html` (Google Fonts, лицензия OFL):

```html
<link href="https://fonts.googleapis.com/css2?family=Comfortaa:wght@600;700&family=Rubik:wght@400;500;600;700&display=swap" rel="stylesheet" />
```

shadcn/ui: компоненты берём как основу, но переопределяем внешний вид под токены: обводка `border-2 border-ink`, тень `shadow-md`, радиус `rounded-md` у кнопок и `rounded-lg` у карточек.

## Карта (Leaflet)

- Подложка OpenStreetMap как есть, атрибуция «© OpenStreetMap» обязательна.
- **Метки событий:** `L.divIcon` с круглой кнопкой 46px (выбранная 60px), фон — цвет вида спорта, обводка 2px, тень `--shadow-sm`, внутри иконка вида спорта. Режим «По заявке» — чёрный кружок с замком в правом верхнем углу. Классы `.pin`, `.pin.is-selected` и `.pin__lock` в `home.html` можно перенести как есть.
- **Попап события:** карточка 300px с цветной шапкой (вид спорта и режим записи), датой, местом, уровнем, местами, организатором и двумя кнопками: «Подробнее» и «Записаться» / «Подать заявку».
- **Список и карта на десктопе** стоят рядом: список высотой с карту (≈780px), прокрутка внутри. **На телефоне** переключатель «Список / Карта» над списком.
- **Запасное состояние** «Карта недоступна» обязательно: в `home.html` открыть с `?nomap`.
