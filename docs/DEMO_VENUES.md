# Демо-площадки для сида (киллер-фича «Место встречи»)

Данные для задачи 3.7 (сид, участник 3). Таблицы: `venues` и `sport_venue_types`. Составил участник 2.

**Всё вымышленное:** названия, адреса, телефоны и контактные лица придуманы. Телефоны вида `+7 900 000-01-NN` в реальности не существуют. Исключение — два реальных парка без контактов (Центральный и Покровский), их координаты взяты из справочных сайтов.
Координаты **приблизительные**: до показа проверить на карте OpenStreetMap, что каждая метка стоит на суше (не в Енисее) и выглядит правдоподобно. Центр карты по умолчанию: **56.0100, 92.8530** (центр Красноярска, около Центрального парка). Река находится восточнее долготы около 92.87, поэтому вымышленные площадки размещены западнее.

| Шахматы | `cafe`, `club` |
| Футбол | `field`, `hall` |
| Баскетбол | `hall`, `yard` |
| Волейбол | `hall`, `field` |
| Бег | `park` |
| Йога | `hall`, `park` |
| Зарядка во дворе | `yard`, `park` |
| Настольный теннис | `club`, `hall` |
| Плавание | `pool` |
| Велоспорт | `park` |

У видов спорта, которые добавил пользователь, связок нет: карта показывает все площадки.

## Как использовать в сиде
- Площадки из таблицы — в `venues` (поле `contact_*` пустое там, где «Контакта нет»).
- Часть демо-событий привязать к площадкам (шахматы к 1–4, футбол к 5–6, плавание к 8), часть оставить со своей точкой, одно событие без координат только с текстовым адресом.
- После сида открыть карту и убедиться, что метки на суше.
