## Площадки (киллер-фича)
Минимум 12 вымышленных площадок в одном городе (кафе, клубы, поля, залы, парки, двор). У кафе и клубов — контактное лицо и телефон. События: часть привязана к площадкам, часть со своей точкой, часть только с текстовым адресом. Контакты демонстрационные, укажите это в README.

## Вход
Это настоящие аккаунты с паролями (Argon2id), созданные сидом. На экране входа есть кнопки «Войти как …» для быстрого входа без ввода данных. Пароли демо-аккаунтов дописать здесь и в README (публичные, только для проверки). Новые пользователи и организации регистрируются обычным способом; админа зарегистрировать нельзя.
