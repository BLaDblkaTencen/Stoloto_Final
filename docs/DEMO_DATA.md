# Демо-данные и аккаунты (владелец — участник 3)

Заполнить вместе с сидом (задача 3.7). Минимальный набор:

| Аккаунт | Роль | Назначение |
| --- | --- | --- |
| user1, user2, user3 | user | обычные пользователи, есть события и записи |
| org_approved | organization | организация после допуска, у неё опубликованные события |
| org_pending | organization | заявка на рассмотрении (для показа допуска админом) |
| org_rejected | organization | отклонённая заявка с причиной |
| admin | admin | модерация |

Пароли демо-аккаунтов и список событий (разные виды спорта, оба режима, события с заявками на рассмотрение, одно снятое) — дописать здесь.
