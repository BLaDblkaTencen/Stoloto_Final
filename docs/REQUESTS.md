# Межзонные запросы
Формат: `[от -> кому] что нужно — статус`

- [1 -> 2] Влить `resolvePublishingOrganization` (ветка `feature/org-organizations`) и реализацию `OrganizationReader` на Drizzle: `POST /api/events` вызовет её для аккаунта `organization`. Контракт `docs/api/events.md` подстроен под запросы участника 2: имена сервисов панели, `limit`/`offset`, `sportId`, `organizationId`, `date`, `view=map`, `GET /api/events/mine` — открыто
- [1 -> 2] Функция для `POST /api/events` с `venueId`: найти площадку и вернуть `Venue` (или 422 `VENUE_NOT_FOUND`). До неё `events` читает строку площадки сам, только чтение — открыто
- [1 -> 3] Демо-данные для сценариев 1, 3–6 (задача 3.7): у `user1` событие по заявке с двумя ожидающими заявками от других пользователей; событие со свободной записью и лимитом мест; одно полностью занятое событие; одно снятое с публикации, на которое кто-то записан; под парой событий вопрос и ответ организатора; события 5+ разных видов спорта, одно из них со «своим» видом спорта (`is_custom`) — открыто
